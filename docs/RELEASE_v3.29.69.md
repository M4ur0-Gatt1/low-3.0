# LOW v3.29.69

## Panel de rigging más claro

- Nuevo bloque **Objetos** siempre visible en Construir, con contador de formas detectadas.
- Acciones directas **Registrar** y **Repartir**, incluso cuando el panel tiene poca altura.
- Construir y Animar muestran solamente las herramientas correspondientes a cada tarea.
- Jerarquía visible y ajustes manuales de pieza plegados para reducir ruido.
- Curvas, movimiento, variantes y deformación quedan disponibles como secciones desplegables.
- Mensajes de ayuda más breves y orientados a la acción.

## Documentos nuevos

- Un lienzo nuevo inicializa automáticamente el documento de animación.
- La Timeline vuelve a aparecer aunque el espacio de trabajo anterior la tuviera oculta.
- Se respetan las ventanas de Timeline ya separadas para configuraciones con dos monitores.
